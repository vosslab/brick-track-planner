# NILTC track specifications snapshot

Downloaded from <https://niltc.org/standards/track-specifications> on 2026-11-24 for use while
planning member layouts. `source.html` is the unmodified source page. The two local diagram files
are the diagrams linked by that page.

Open `source.html` in a browser with this directory available to read the original article. The
planner treats the current public NILTC page as authoritative whenever it differs from this
snapshot.

Files:

- `double-straight-standard.jpg` shows the dual mainline straight standard.
- `r120-r104-curve-standard.png` shows the mainline corner standard.
